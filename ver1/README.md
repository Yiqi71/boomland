## 使用说明

- 文件名表达 IA 归属；同一页面的不同状态保留为独立快照。
- “旧任务参考”只表示可复用的说明结构，不是已实现的新功能。
- 页面中的旧导航、品牌、文案、表单和链接保持原样；原站 `/seasons` 等路径不会自动跳到本地重命名文件，请使用索引切换。
- 这些文件是网页快照；快照中的按钮不代表离线业务可用，外部资源或原站服务仍可能不可用。

## 本批快照没有覆盖的 IA 页面

- 发现：首页、项目广场、游乐场地图、社区活动的独立页面。
- 赛季：企业命题详情、资源包、权益确认、独立结算成绩及项目榜单。
- 项目：项目详情与编辑、团队管理、作品发布与详情、作品版本、积分流水、真正的 M1—M4 提交和认证、R0—R6 结果核验、奖励与赛后合作。
- 我的：注册登录、个人资料与履历、个人 Boom 值、人工入群、队伍登记、选命题与项目上传、我的待办、贡献确认与异议。
- 主办方／管理员：命题配置、评分预算、结算治理、权限管理和审计的独立页面。
- 评委／核验员：评审待办、作品评分、阶段与个人贡献审核、结果核验。
- 企业：我的命题、资源管理、命题报告、合作跟进。

没有用占位 HTML 冒充上述缺失页面。源页面的导航里出现相关名称，也不算实际覆盖。
